# 🤖 AI Employee Chatbot

An AI-powered Employee Support Chatbot built using Next.js, FastAPI, and Google Gemini AI.

## 🚀 Features

- AI-powered chatbot responses
- Modern frontend using Next.js
- Backend API using FastAPI
- Google Gemini AI integration
- Employee support assistant
- Simple and responsive UI

---

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- Tailwind CSS

### Backend
- FastAPI
- Python
- Uvicorn

### AI Model
- Google Gemini AI
